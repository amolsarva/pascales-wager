Remaining Steps For You

  1. Open Supabase for the production project.
  2. Open the SQL editor.
  3. Run docs/supabase-alpha-readiness.sql.
  4. Wait a few seconds for PostgREST schema reload.
  5. Run npm run audit:schema locally.
  6. When the audit passes, run npm run smoke:alpha.
  7. Try creating a custom advisor at /advisors.

Why this is still needed

Production currently lets the app work through compatibility fallbacks, but Supabase REST still hides or rejects some expected tables/columns: sessions, session_summaries, advisors, messages.session_id, and optional memory columns.

How To Test

npm run build
npm run audit:schema
npm run smoke:alpha

Expected before the Supabase SQL step: npm run build passes, npm run smoke:alpha should pass, and npm run audit:schema reports the remaining schema capability failures.

Expected after the Supabase SQL step: all three commands should pass.

Manual Alpha Checklist

  1. Sign up with a fresh email and confirm onboarding redirects to /onboarding.
  2. Complete onboarding and confirm /home loads dashboard counts.
  3. Ask one chat question and confirm the answer streams.
  4. Use “Remember this” on an assistant response and verify it appears in Mirror/Timeline.
  5. Ask the Council a question with 2-3 advisors and verify the synthesis appears.
  6. Create a session summary from chat or Council.
  7. After running the Supabase SQL, create and edit a custom advisor.
